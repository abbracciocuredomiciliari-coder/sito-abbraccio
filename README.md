## 🚀 Deploy e Pubblicazione

### Setup Locale
```bash
# Clona il repository
git clone https://github.com/abbracciocuredomiciliari/sito-abbraccio.git
cd sito-abbraccio

# Installa le dipendenze
npm install

# Avvia il server locale
npm start
```

### Deploy su Vercel
1. **Connetti GitHub a Vercel**
2. **Importa il repository** `sito-abbraccio`
3. **Configura le variabili d'ambiente** (se necessarie)
4. **Deploy automatico** ad ogni push

### Dominio Personalizzato
Su Vercel:
1. Vai a `Settings → Domains`
2. Aggiungi il tuo dominio (es: `abbracciocuredomiciliari.it`)
3. Configura i DNS come indicato

## 🔧 Modifiche e Manutenzione

### Per modificare il sito:
1. **Apri i file** in un editor di codice
2. **Modifica** HTML, CSS o JavaScript
3. **Testa localmente** con `npm start`

1. **Sostituisci gli URL** delle immagini nell'HTML
